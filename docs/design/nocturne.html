요약

엔트로피는 ‘무질서’라는 비유보다 가능한 미시 상태의 수로 이해해야 하고, 고립계에서는 줄어들지 않는다. 오늘 강의는 이 한 문장을 열기관, 부등식, 통계의 세 길로 다시 걸었다.

제2법칙의 두 가지 진술

  • 켈빈–플랑크 진술 — 하나의 열원에서 열을 받아 전부 일로 바꾸는 순환 기관은 만들 수 없다.
  • 클라우지우스 진술 — 다른 변화 없이 차가운 곳에서 뜨거운 곳으로 열이 저절로 흐르지 않는다.
  • 두 진술은 동치다. 하나가 깨지면 다른 하나도 깨진다는 것을 귀류법으로 보였다.

카르노 기관과 효율의 상한

  • 가역 기관의 효율은 작동 물질과 무관하고 두 열원의 온도로만 정해진다. η = 1 − Tc / Th
  • 300 K와 600 K 사이에서 작동하면 최대 효율은 50 %. 실제 기관은 언제나 이보다 낮다.
  • 효율 문제는 온도를 반드시 켈빈으로 바꾸고 시작할 것.

클라우지우스 부등식과 엔트로피의 정의

  • 임의의 순환 과정에서 ∮ δQ / T ≤ 0. 등호는 가역 과정에서만 성립한다.
  • 여기서 상태 함수 dS = δQrev / T 를 정의한다.
  • 고립계에서는 ΔS ≥ 0 — 엔트로피 증가의 법칙.

통계적 해석

  • 볼츠만의 식 S = kB ln W. W는 하나의 거시 상태에 대응하는 미시 상태의 수.
  • 기체의 자유 팽창: 부피가 두 배가 되면 ΔS = N kB ln 2. 열이 드나들지 않아도 엔트로피는 늘어난다.
  • ‘무질서’는 비유일 뿐이다. 답안에는 미시 상태의 수로 쓸 것.

시험과 과제
