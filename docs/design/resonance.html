김 교수서연도윤 용어벨레이디의 모순스래싱LRU
편집 모드 — 문장을 눌러 고치면 자동 저장돼요. 화자 이름을 누르면 화자를 바꿀 수 있어요.

요약 노트

가상 메모리는 필요한 페이지만 메모리에 올려 실행하는 기법이고, 어떤 페이지를 내보낼지가 성능을 좌우한다.

핵심 개념

  • 요구 페이징필요한 페이지만 그때그때 올린다. 참조의 지역성 덕분에 가능하다.
  • 페이지 폴트메모리에 없는 페이지에 접근하면 발생. 디스크에서 가져오므로 메모리 접근보다 수만 배 느리다.
  • 벨레이디의 모순FIFO에서는 프레임을 늘려도 폴트가 오히려 늘 수 있다.
  • LRU와 클럭LRU는 스택 알고리즘이라 모순이 없지만 구현 비용이 커서, 실제로는 참조 비트 하나로 근사하는 클럭 알고리즘을 쓴다.
  • 스래싱폴트가 너무 잦아 CPU가 교체만 하는 상태. 작업 집합 모델로 막는다.

시험 포인트 교수님이 직접 강조했어요

  • FIFO와 LRU를 비교해, 벨레이디의 모순이 한쪽에서만 생기는 이유 설명하기
  • 유효 접근 시간 = (1 − p) × 메모리 접근 시간 + p × 폴트 처리 시간
